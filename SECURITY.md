# Security Policy

## Reporting a vulnerability

Report vulnerabilities privately through [GitHub security advisories](https://github.com/tnastalyai/machine-fault-triage/security/advisories/new). Do not open a public issue.

Include the affected version, a description of the issue and steps to reproduce it. You will receive an acknowledgement within seven days.

## Scope

Reports of particular interest:

- Prompt injection through fault reports or document content that changes tool behaviour or leaks data
- Retrieval returning content that belongs to another tenant
- Personal data reaching a model provider or a trace sink
